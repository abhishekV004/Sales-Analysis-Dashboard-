📊 Sales Analysis Dashboard

Overview
This project is a Sales Analysis Dashboard built in Power BI to analyze and visualize key sales metrics. It includes insights on total sales, regional distribution, product performance, customer segmentation, and time-based trends.

Developed by Abhishek Vishwakarma as a part of a business intelligence practice project.

🚀 Features
Total Sales Summary (985K)

Monthly Actual vs Target chart

Sales Trend Over Weeks

Top 3 Customers

Product-wise Sales Ranking

Region-wise Contribution (Donut Chart + Map)

Dynamic Filters for Months and Regions

Light/Dark Mode Toggle

📌 How to Use
Open the .pbix file in Power BI Desktop.
Ensure both Excel source files are in the same directory (for data refresh).
Click Refresh to load the latest data.
Use filters to explore insights dynamically.

🧠 Insights You Can Gain
Which products are top sellers?
Which regions are underperforming?
Who are the top customers driving sales?
How sales are trending monthly and weekly?
