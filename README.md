
# 📊 Sales Analysis Dashboard

## 📝 Overview  
This project presents a **Sales Analysis Dashboard** built in **Power BI**, designed to explore and visualize key sales performance metrics. It provides detailed insights into:

- Total and regional sales performance  
- Product-wise and customer-wise contributions  
- Monthly and weekly trends  
- Dynamic filtering and theme toggling

Developed by **Abhishek Vishwakarma** as part of a business intelligence practice project.

---

## 🚀 Features

- 📈 **Total Sales Summary** (985K)
- 📊 **Monthly Actual vs Target** Comparison
- 📉 **Weekly Sales Trend**
- 🏆 **Top 3 Customers**
- 🧾 **Product-wise Sales Ranking**
- 🌍 **Region-wise Contribution** (Donut Chart & Map)
- 🎛 **Interactive Filters** for Months and Regions
- 🌗 **Light & Dark Theme Toggle**

---

## 📌 How to Use

1. Open `Sales Analysis Dashboard.pbix` in **Power BI Desktop**.
2. Make sure the Excel data files are in the **same directory** as the PBIX file.
3. Click on **Refresh** to load or update the data.
4. Use the interactive filters and explore different views and insights.
